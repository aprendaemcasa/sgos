# SGOS — Sistema de Gerenciamento de Ordens de Serviço

Projeto acadêmico com interfaces desktop em C# Windows Forms.

O código-fonte está na pasta [`SGOS-CSharp-Interfaces`](./SGOS-CSharp-Interfaces).

## Como executar
1. Baixe o repositório.
2. Abra `SGOS-CSharp-Interfaces`.
3. Execute `Preparar-e-Abrir-SGOS.bat`.
4. Depois da publicação, abra `Aplicativo/SGOS.exe`.

## Escopo
Interfaces demonstrativas de login, painel, clientes, serviços, ordens de serviço e usuários. Esta versão não possui banco de dados nem gravação de cadastros.
