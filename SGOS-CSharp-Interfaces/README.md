# SGOS — Interfaces em C# Windows Forms

Esta pasta contém uma versão demonstrativa das interfaces do Sistema de Gerenciamento de Ordens de Serviço (SGOS), feita em C# com Windows Forms.

## Conteúdo
- Tela de login demonstrativa
- Painel principal com indicadores e atividades
- Telas visuais de clientes, serviços, ordens de serviço e usuários
- Script para publicar um executável Windows autocontido

## Como abrir
1. Baixe ou clone o repositório.
2. Abra a pasta `SGOS-CSharp-Interfaces`.
3. Dê dois cliques em `Preparar-e-Abrir-SGOS.bat`.
4. Aguarde a publicação. O executável será criado em `Aplicativo/SGOS.exe`.

Depois da primeira publicação, abra diretamente `Aplicativo/SGOS.exe`, sem precisar do CMD ou Visual Studio.

## Requisitos para preparar
- Windows 64 bits
- SDK .NET 8 instalado

## Limitações desta versão
As telas são demonstrativas. O login não valida credenciais e os dados exibidos são exemplos; não há conexão com banco de dados nem persistência de cadastros.
